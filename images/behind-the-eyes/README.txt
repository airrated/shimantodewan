Book cover images go here, named exactly:

  original.jpg
  inside.jpg
  influence.jpg
  shadows.jpg

Lowercase, no spaces. The pages reference them at
/images/behind-the-eyes/<name>.jpg

Suggested: 3:4 portrait, around 900 x 1200, under 150 KB each.
JPG for photographic mockups, PNG only if the mockup needs transparency
(rename the reference in the HTML if you use PNG).

Until these files exist, each cover slot shows the book title instead,
so the layout never breaks.
